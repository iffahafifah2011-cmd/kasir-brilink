Backup seluruh data

Unduh satu file JSON yang berisi seluruh data ruang toko: transaksi, saldo, pecahan cash, piutang, pelunasan, mutasi, refund, rekonsiliasi, tarif, dan pengaturan pendukung.

⬆️

Restore data

Pilih file backup BRILink Smart Kasir berformat JSON. Restore akan mengganti seluruh isi ruang data toko yang sedang dibuka.

Sebelum restore, aplikasi akan mengunduh backup kondisi data saat ini sebagai salinan pengaman. Jangan tutup aplikasi sampai proses selesai.
